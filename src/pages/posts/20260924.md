本人刚刚做了份二级 NCRE Web 的试卷，成绩如何估计很清楚了，不然也不可能出现本文章。

其实我自己也很清楚，自己在 JavaScript 领域确实不太熟练，但是为什么都快 2027 年了，还考这些 HTML 4 的东西呢？HTML 5 之后都直接不存在版本号了，都直接持续性更新了，还使用上古代码神器，这种完全是跟不上时代发展的表现。

![繁星点点的夜空。](/images/PixPin_2026-09-24_14-27-33.webp)

既然号称 Web 考试，为什么不能用现代 Web 的基础标准来考？考一点内联样式，然后配一点 `.scss` 语法，这种才是现代化的表现。使用记事本写代码，这是把网线拔了多少年的体现。

二级不考了。还是天天沉迷在 GitHub 吧，看着我去年贡献的 1,878 次代码。
